O que é HTML?

HTML (HyperText Markup Language) é a linguagem de marcação utilizada para criar páginas web. Ela é formada por elementos como tags, atributos e valores, isso ajuda a identificar os elementos da página.

O que significa sigral HTML?

HyperText Markup Language (Linguagem de Marcação de Hipertexto).

Quem criou o HTML, onde criou e porque criou?

Tim Berners-Lee criou o HTML em 1990 no CERN (European Organization for Nuclear Research) para permitir a compartilhamento de informações entre pesquisadores. Indicando ao navegador quais elementos existem na página.
